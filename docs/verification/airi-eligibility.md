# AIRI e il catalogo gratuito

Il test storico su Apple Silicon ha verificato il ciclo 0.15.2 → 0.15.4 con i DMG ufficiali. Nella versione stabile 0.15.4 la dashboard desktop vende abbonamenti e ricariche Flux. La scheda e la ricetta escono dal catalogo gratuito. La modifica al launcher non tocca i file o le app già installate, che continuano a essere gestibili dal sistema operativo.
