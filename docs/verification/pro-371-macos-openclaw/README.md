# OpenClaw su Apple Silicon

Il 27 novembre 2026 NativeBackend ha installato OpenClaw 2026.11.9, aggiornato a 2026.11.10 e rimosso il bundle in un profilo isolato sull’Air. I DMG ufficiali arm64 sono stati verificati con SHA-256, Gatekeeper e il Developer ID Foundation. Il marker del profilo è stato conservato. I package sono stati riletti dalla cache isolata dal motore. L’avvio della GUI e del gateway resta da provare.
