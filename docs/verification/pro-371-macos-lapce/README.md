# Lapce su macOS Apple Silicon

NativeBackend ha scaricato e verificato i DMG ufficiali Lapce, installato 0.4.5, aggiornato a 0.4.6 e rimosso in un Cestino privato. Sono stati conservati i dati sintetici. Entrambe le release recano Developer ID Application, Team CYSGAZFR8D, e aderiscono ai controlli strict e Gatekeeper. Mac Apple Silicon, profilo temporaneo. La finestra di Lapce resta da provare: questo ciclo copre la gestione dal backend.

Installazione 17,050 s, aggiornamento 6,766 s, rimozione 0,020 s. Lapce richiede macOS 11 o più recente. La selezione vincola il nome non versionato del DMG al repository, al tag stabile, al digest e alle dimensioni ufficiali. Il test regressione del selettore verifica il pacchetto atteso e i rifiuti.
