# RapidRAW su Ubuntu x64

Il 27 novembre 2026 il motore nativo ha installato RapidRAW 1.7.0, aggiornato a 1.7.1 e rimosso il pacchetto in un profilo isolato su Ubuntu 24.04 amd64. Ogni download ha coinciso con lo SHA-256 ufficiale. La sentinella dati è rimasta intatta. [Rilascio 1.7.0](https://github.com/CyberTimon/RapidRAW/releases/tag/v1.7.0) · [Rilascio 1.7.1](https://github.com/CyberTimon/RapidRAW/releases/tag/v1.7.1)

La finestra dell’editor si apre senza login nella prova offline su entrambe le versioni, anche da menu con l’icona. La prova riguarda il ciclo del pacchetto e l’avvio dell’editor.
