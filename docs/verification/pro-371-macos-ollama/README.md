# Ollama su Apple Silicon

Il 27 novembre 2026 NativeBackend ha installato Ollama 0.40.17, aggiornato a 0.40.18 e rimosso l’app in un profilo isolato sull’Air. I DMG ufficiali sono stati verificati con SHA-256 e firma Developer ID di Infra Technologies. I marker del profilo sono rimasti intatti. Il ciclo non ha avviato la GUI, il server locale o un modello.
