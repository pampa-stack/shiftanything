## Verifiche

- Conteggi dall’API GitHub dei repository sorgente, licenze collegate ai testi ufficiali e date dalle rispettive release o tag. SoftEther Client e Mullvad Browser riportano dimensioni dei soli asset desktop corrispondenti a quelle piattaforme.
- Ho aperto e letto 10 loghi e 17 screenshot ufficiali. I due loghi ICO di SoftEther e Ackee sono le risorse originali. La licenza indicata riguarda il software e la provenienza delle immagini è documentata. La ripubblicazione dei marchi va valutata sui termini del titolare.
- Due MCP documentati ufficialmente, Zammad 7.3 e Frappe Helpdesk v16. Cinque API ufficiali, GLPI, Harbor, Healthchecks, Ghost e Ackee. Metadati e schermate verificati via web. Installazione, ciclo aggiornamento/rimozione e connessioni agent non eseguiti.
