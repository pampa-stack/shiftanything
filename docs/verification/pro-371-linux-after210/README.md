## Riproduzione

Usare un guest Ubuntu 24.04 x86-64 temporaneo chiamato `shift-launcher-qa`, con un utente senza privilegi chiamato `qa`. Il guest deve avere Flatpak, OSTree, D-Bus, Xvfb, xauth, xdotool, x11-apps, x11-utils e xfwm4. Servono una connessione a Flathub per i pacchetti e almeno 9 GiB liberi nel profilo di prova.

Nel clone temporaneo copiare `verify.rs` in `crates/native/src/bin/flatpak-after210-cycle.rs` e compilare `cargo build --locked -p artcraft-launcher-native --bin flatpak-after210-cycle`. Copiare l'eseguibile come `~/flatpak-after210-cycle`, `candidates.tsv` come `~/after210-candidates` e `run.sh` come `~/after210-run.sh` nel guest. Eseguire `dbus-run-session -- bash ~/after210-run.sh pitivi 82` con un display X libero. Per Actual Budget e Natron usare gli ID `actual` e `natron` con altri display liberi. Il ref corrente deve corrispondere alla seconda revisione registrata. L'app viene rimossa anche se la verifica si interrompe. Il profilo QA è usa e getta.
