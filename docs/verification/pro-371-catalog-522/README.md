## Verifiche e limiti

- Probe web sui due lotti. 106 risposte HTTP riuscite per fonti, immagini e documenti dei primi candidati. Verifica a parte dei media delle 17 schede finali, 45 file su 45 scaricati e decodificati. Controllate visivamente le anteprime su sfondo scuro nei tre PNG di prova. ZITADEL e MeshCentral hanno poi ricevuto due screenshot ufficiali dell'interfaccia ciascuna, letti singolarmente.
- Authelia dispone di pannello utente per iscrivere dispositivi 2FA e gestire le proprie credenziali. La configurazione dell'istanza è amministrata tramite file. [Note Authelia 4.38](https://www.authelia.com/blog/4.38-release-notes/) [Note Authelia 4.39](https://www.authelia.com/blog/4.39-release-notes/)
- ZITADEL ha una console di amministrazione nell'istanza self-hosted. MeshCentral è raffigurato con schermate della guida ufficiale che precedono la release corrente. Gli screenshot BleachBit documentano una versione precedente e il port macOS ufficiale è sperimentale. [Console ZITADEL](https://zitadel.com/docs/guides/manage/console/console-overview) [Guida MeshCentral](https://docs.meshcentral.com/meshcentral/#after-agent-install) [BleachBit macOS](https://www.bleachbit.org/download/mac)
- SFTPGo Community documenta anche Homebrew/macOS e FreeBSD. La foto raffigura il client web disponibile nella Community. La scheda OpenCTI riguarda l'edizione Apache, il repository segnala l'edizione Enterprise separatamente. Infisical separa `ee/` dal progetto MIT. Il pannello BunkerWeb identificato mostra il piano FREE. [SFTPGo](https://docs.sftpgo.com/latest/installation/) [OpenCTI](https://github.com/OpenCTI-Platform/opencti#readme) [Infisical LICENSE](https://github.com/Infisical/infisical/blob/main/LICENSE) [BunkerWeb](https://docs.bunkerweb.io/latest/web-ui/)
- Verifica documentale e delle immagini. Le piattaforme di una scheda server descrivono l'host, il client web si usa dal browser. Installazione, avvio e aggiornamento delle app rimangono da provare in sandbox.

## Scartate

- WGDashboard, wg-easy, NetBird, Pangolin, WireGuard per Windows, Tunnelblick, AmneziaVPN e OpenVPN GUI erano già nel catalogo. Headplane è un pannello distinto per Headscale.
- Netmaker usa per il pannello ufficiale la SSPL, diversa dalla licenza Apache del backend Community. [Pannello](https://github.com/gravitl/netmaker-ui/blob/master/LICENSE.txt) [Backend](https://github.com/gravitl/netmaker/blob/v1.8.0/LICENSE.md)
- Firezone rende disponibile il sorgente. Per il control plane autogestito il progetto non dà supporto o istruzioni e lo suggerisce per usi hobbistici o educativi. [FAQ](https://www.firezone.dev/kb/faq#can-i-self-host-firezone)
- Tinyauth ha una schermata di autenticazione e il pannello utente non è documentato. Yubico Authenticator richiede un dispositivo YubiKey proprietario.
- WireGuard UI di ngoduykhanh e wg-access-server di Place1 erano senza sviluppo recente. Il fork Freifunk di wg-access-server aveva 694 stelle. BlockBlock e KnockKnock erano sotto 1.000 stelle.
