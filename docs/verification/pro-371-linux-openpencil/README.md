# OpenPencil su Linux x64

Il test usa le AppImage stabili ufficiali 0.16.0 e 0.17.0. Per entrambe dimensione e digest dei pacchetti installati corrispondono all'API GitHub. I digest corrispondono anche al file `SHA256SUMS` del produttore. La ricetta richiede Linux x64 e FUSE 2. Un tag successivo può essere rilevato ma richiede la ricevuta del nuovo AppImage prima dell'installazione. [Release 0.16.0](https://github.com/open-pencil/open-pencil/releases/tag/v0.16.0), [release 0.17.0](https://github.com/open-pencil/open-pencil/releases/tag/v0.17.0), [licenza MIT](https://github.com/open-pencil/open-pencil/blob/v0.17.0/LICENSE).

Il 27 novembre 2026 un ciclo in un guest Ubuntu 24.04 amd64 ha verificato installazione, avvio dell'editor, aggiornamento, secondo avvio e rimozione con il NativeBackend. La voce desktop e l'icona usano l'identità della finestra, `OpenPencil`. Le aperture si fermano al benvenuto, con rete limitata a loopback, prima di collegare account, AI o MCP. La rimozione preserva il file utente di prova e lascia vuota la cartella delle app. [Finestra 0.16.0](open-old.png), [finestra 0.17.0](open-new.png), [log](native-lifecycle.txt), [sonda Rust](../pro-371-linux-desktop-expansion/verify_native_appimages.rs).
