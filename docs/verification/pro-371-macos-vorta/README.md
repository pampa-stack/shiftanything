# Vorta su macOS Apple Silicon

Installazione ufficiale 0.12.1, aggiornamento 0.12.2 e rimozione nel Cestino temporaneo riusciti tramite NativeBackend. Il dato sintetico è rimasto intatto. SHA-256, versione, bundle ID, Developer ID e Gatekeeper controllati. Tempi osservati 6,776 s, 6,903 s e 0,018 s. L'avvio della finestra di Vorta e l'esecuzione di un backup restano da provare. [Log](vorta-cycle.log)

Il pacchetto verificato richiede macOS 14.4 o successivo. Il selettore controlla l'asset e il tag stabili. Il controllo sul sistema ora considera anche la versione minore di macOS.
