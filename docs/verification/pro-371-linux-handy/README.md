# Handy su Linux x86-64

Il 27 novembre 2026, NativeBackend su Ubuntu x86-64 ha scaricato e installato l’AppImage ufficiale 0.10.1, aperto la finestra senza rete, aggiornato a 0.10.2, riaperto la finestra e rimosso il pacchetto con la voce desktop. Il dato sintetico è rimasto intatto. SHA-256 e firme Minisign del produttore sono stati verificati per entrambe le release.
