# Cherry Studio 2.2.3

Il pacchetto Debian amd64 ufficiale ha superato installazione, aggiornamento dalla 2.2.2 e rimozione con APT in Ubuntu 24.04. Le due versioni hanno aperto la finestra e i dati di prova sono rimasti dopo la rimozione. La prova riguarda il pacchetto del produttore.

Il pacchetto include `/opt/Cherry Studio/resources/app.asar.unpacked/resources/cherry-studio/license.html`. Lo SHA-256 `f27bf38d7e5400fee614bc0ec4695936ff2cbd0136270b7bd8b9cdedd0581d31` corrisponde al file del tag v2.2.3. Nel file il produttore richiede un accordo commerciale per le organizzazioni con più di dieci persone che possono usare il software. La scheda e la ricetta Mac escono dalla prossima beta per questa condizione.
