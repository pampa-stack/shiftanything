# OpenCode Desktop su macOS Apple Silicon

Il 27 novembre 2026 NativeBackend ha installato OpenCode Desktop 2.4.1, aggiornato a 2.4.2 e rimosso il bundle con un solo binario di prova. Il MacBook Air usava un profilo isolato con cartelle Applicazioni e Cestino dedicate. I DMG ufficiali arm64 hanno superato la verifica SHA-256, firma Developer ID e notarizzazione. Il ciclo riguardava installazione, aggiornamento e rimozione.

Il launcher cerca le release desktop stabili v2. Con la quota API di GitHub esaurita, la prova di aggiornamento ha incrociato versione e SHA-256 del feed desktop di OpenCode con il manifesto SHA256SUMS della release GitHub. Il catalogo mostra la versione e le dimensioni dei pacchetti desktop v2.4.2.
