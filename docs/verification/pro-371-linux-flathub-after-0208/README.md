# Cicli Linux x64 dopo 0.20.8

Il 27 novembre 2026 abbiamo installato, aperto, aggiornato, riaperto e rimosso le app elencate sotto con NativeBackend 0.20.8. Il test ha usato profili separati su un guest Ubuntu 24.04 amd64 con display X11 privato. Nelle aperture Flatpak la rete dell'app era limitata al loopback e i file del sistema ospite erano esclusi. I pacchetti erano firmati da Flathub (`4184DD4D907A7CAE`). Prima di aggiornare, abbiamo confermato che il motore rifiuta la modifica e la rimozione di una copia esterna. Abbiamo simulato una precedente installazione di proprietà del launcher nel profilo di prova e verificato la conservazione del dato sintetico dopo aggiornamento e rimozione.
