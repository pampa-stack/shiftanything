# Cicli nativi AppImage, secondo lotto

Prova del 27 novembre 2026 su VPS2, Ubuntu 24.04.5 x86-64. Questa tranche include MuseScore Studio e LosslessCut. Gli AppImage arrivano dai repository upstream gratuiti. La prova chiama il NativeBackend di SH*FTER, verifica manifesto, byte, SHA-256 del registro release, icona e file desktop. Usa Bubblewrap con HOME privato, DBus e display Xvfb 1440×900, rete disattivata durante l’esecuzione delle app e nessun mount FUSE. L’installazione e l’aggiornamento del backend scaricano in HTTPS. L’avvio dal menu usa `gio launch`. I tempi includono la conferma visiva di una finestra X11 stabile e variano col carico VPS.

- MuseScore Studio dispone di un editor gratuito GPL-3.0; l’AppImage ufficiale include l’icona `share/icons/hicolor/128x128/apps/mscore4portable.png`. La finestra mostra onboarding e area di notazione. Il primo avvio ha aperto una splash di breve durata. Il banco è stato corretto per aspettare una finestra stabile ed è ripartito sullo stesso profilo isolato.
