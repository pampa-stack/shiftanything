# Collegamento LibreOffice a Sh*ftAnything

L’upstream distribuisce i DMG sul dominio di The Document Foundation. La sorgente nativa esistente si aspetta un repository GitHub e un percorso `releases/download`. L’indice stabile TDF elenca sia il ramo corrente sia il precedente, quindi va ordinato per versione numerica e filtrato alle directory strutturate `X.Y.Z/`. Per ogni directory candidata il formato Apple Silicon è `https://download.documentfoundation.org/libreoffice/stable/{version}/mac/aarch64/LibreOffice_{version}_MacOS_aarch64.dmg`. Il digest proviene dalla stessa URL con suffisso `.sha256`, con corrispondenza esatta del nome. Il mirror viene scelto da TDF e i pacchetti provati sono stati consegnati tramite HTTPS. [Indice stabile TDF](https://download.documentfoundation.org/libreoffice/stable/)

Il bundle `org.libreoffice.script` è firmato da The Document Foundation, Team ID `7P5S3ZLCN7`. Il numero stabile `26.8.2` corrisponde al bundle `26.8.2.2`. `detect::macos::read_bundle` usa `version::parse`, che respinge quattro componenti. Serve normalizzazione vincolata a LibreOffice, con il quarto numero mantenuto come metadato se serve al referto. La firma, il team e il digest restano condizioni di accettazione.

Percorso di implementazione richiesto per offrire installazione e aggiornamento: estendere la ricerca release con una sorgente TDF limitata a questa app, mantenere la validazione stretta di URL e digest e riusare il ciclo native DMG. I pacchetti di un ramo stabile che esce dall’indice passano nell’archivio TDF con numero di build completo. Un’eventuale selezione di versioni archiviate deve trattare esplicitamente questo cambio di percorso. [Archivio TDF](https://downloadarchive.documentfoundation.org/libreoffice/old/)
