# CopyQ e qBittorrent su Linux x86-64

Il 27 novembre 2026 NativeBackend ha installato, aperto, aggiornato e rimosso CopyQ e qBittorrent su VPS Strumenti. Il banco usava Flatpak utente, profili isolati, D-Bus e Xvfb dedicati. Le due revisioni di ciascuna app sono firmate dal repository Flathub. I dati sintetici sono rimasti intatti dopo aggiornamento e rimozione.

- CopyQ, `com.github.hluk.copyq`, 16.0.0 → 17.0.0. Finestra mostrata con `show` dopo l’avvio nell’area di notifica.
- qBittorrent, `org.qbittorrent.qBittorrent`, 5.3.0 → 5.3.1. Finestra aperta senza torrent o connessioni.
