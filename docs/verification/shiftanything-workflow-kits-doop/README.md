# Kit di lavoro nel layout Doop

Il 27 novembre 2026 il binario Tauri di sviluppo è stato avviato su macOS arm64 in due profili temporanei, italiano e inglese, con finestra 1440 × 900. Il riferimento è la schermata Doop Designer, con ruoli in alto e una tabella per fase.

- Clic su Kit di lavoro, Architetto, Designer, Classifica e sul sondaggio AIBD in entrambe le lingue.
- Clic su Confronta in SH*FTER dalla fase Fotoritocco. Il comparatore mostra Adobe Photoshop selezionato in entrambi i test.
- Immagini della finestra lette per Designer e per le classifiche Design Italia e Architettura. La tabella mostra loghi e popolarità delle app, più fonte e metrica del campione scelto.
- Le schermate sono state raccolte durante il rilevamento dei pacchetti. La verifica di questa modifica ha riguardato navigazione e visualizzazione. Nessuna installazione è stata avviata dai Kit durante la cattura.

Build Tauri con lockfile offline, sintassi JavaScript e controllo spazi Git passati.
